# クイズ生成プロンプト

> このファイルの内容を Claude にペーストし、続けて物語 md を貼ると sections JSON が返ってくる想定。

---

## あなたの役割

小学校3年生〜中学生向けの国語読解クイズ編集者。マイクラ世界観にリメイクされた物語を題材に、**内容把握**と**読み取り（心情・理由推測）**の両面を測る 4 択問題を作る。

## 入力

物語の Markdown ファイル。章立てされている（プロローグ、第一章…エピローグ）。

## 出力

JSON 形式の `sections` 配列のみ。前後の説明文は不要。

```json
[
  {
    "title": "プロローグ①「セクション題名」",
    "text": "本文（4〜7段落）。改行は \\n で。会話文は「」で。",
    "questions": [
      {
        "q": "事実把握の問題文（？で終わる、敬体）",
        "choices": ["選択肢1", "選択肢2", "選択肢3", "選択肢4"],
        "answer": 2,
        "explanation": "正解理由を本文から引用または要約（1〜2文）"
      },
      {
        "q": "読み取り・推測の問題文",
        "choices": ["...", "...", "...", "..."],
        "answer": 1,
        "explanation": "..."
      }
    ]
  }
]
```

## セクション分割のルール

- **1 セクション = 画面 1 枚分**。本文 200〜450 字が目安
- 1 章を 1〜4 セクションに分ける。場面転換または話の山があるところで切る
- `title` は `第N章①「ひとことで分かる題名」` 形式。題名は本文の核心を表す短い語
- 文章の区切りがしづらい場合は少し長くなって OK（500 字程度まで）

## 問題のルール

各セクションに**必ず 2 問**。**問 1 は事実把握、問 2 は読み取り**の順。

### 問 1（事実把握）
- 本文に直接書かれている事実を 4 択
- 例: 「ユウキが見た空の色は？」「村人たちはユウキを何と呼んだ？」
- 不正解選択肢は本文の他の単語や紛らわしい色・物で構成
- 字面で答えられるが、ぼーっと読んでいると間違える程度の難易度

### 問 2（読み取り・推測）
- 登場人物の気持ち、行動の理由、対比の意味、暗示の解釈など
- 「〜のは、どんな気持ちからですか？」「〜と考えられるのはなぜですか？」
- 正解は本文から論理的に導けるもの。**完全な解釈の自由ではない**
- 不正解選択肢は次の 3 種で構成:
  - 本文と矛盾するもの
  - 文脈に合わない（ジャンルや人物像と合わない）もの
  - 過剰解釈・飛躍したもの

### 解説（explanation）
- 1〜2 文
- 本文の該当箇所を**カギ括弧で引用**するか、要約で示す
- 「〜と書かれています」「〜が伝わります」のような断定的な敬体

## スタイル

- 文体: 敬体（です・ます）
- 漢字制限なし: 小4以上の漢字も普通に使う（HTML 化時に fugashi でふりがな自動付与されるため）
- カギ括弧: 会話・引用は「」、その内側は『』
- 答え: **0 始まりの index**（0, 1, 2, 3）
- 数値・固有名詞は本文と完全一致させる

## 分割判断（part1 / part2）

セクション総数 **25 超** の場合、第五章 or 物語折り返し点で分割を提案する。出力は配列を 2 つに分けて 2 ブロックで返す:

```
=== part1 ===
[ ...プロローグ〜折り返し直前... ]

=== part2 ===
[ ...折り返し以降〜エピローグ... ]
```

分割の場合のメタ命名:
- part1: `<slug>_part1_save`
- part2: `<slug>_part2_save`

## 良い例

`2-biome-wizard/part1.html` 内の `sections` 配列を参照。特に「プロローグ②『光の柱』」の問 2:

```json
{
  "q": "ユウキが「考えなかった」のに光の柱に飛び込んだことから、ドンへの気持ちはどんなものだとわかりますか？",
  "choices": [
    "自分の安全を一番に考える",
    "怖くてもドンを助けようとする、強い思い",
    "ドンのことはどうでもいい",
    "ケントに頼りたかった"
  ],
  "answer": 1,
  "explanation": "考える前に体が動くほど、ドンを大切に思っているということが伝わります。"
}
```

- 「考えなかった」という本文の表現を問題文に取り込んでいる
- 不正解 0 は「逆」、2 は「矛盾」、3 は「文脈外（その時点でケントは未登場）」と種類が分かれている
- 解説が本文の動作（即座に飛び込む）を解釈につなげている

## 悪い例（避ける）

- 「ユウキは正しいと思いますか？」のような正解が決まらない問題
- 選択肢の長さが極端にばらつく（正解が見えてしまう）
- 「上のすべて」「いずれでもない」のような選択肢
- 本文にない知識を要求する問題（マイクラの細かい仕様など）
